↗通过登录添加

在浏览器中完成 ChatGPT 账号授权

  1. 生成链接后，在新窗口完成登录。
  2. 跳转到 localhost 后，即使提示无法访问，也请复制地址栏完整链接。
  3. 将链接粘贴至回调输入框，提交保存。

重新生成链接会作废上一次未完成的登录。登录已有账号会更新其认证并保留原名称；当前账号会自动应用新认证。
